**SportOrg Tourist** — модифицированная версия программы SportOrg, адаптируемая под задачи проведения туристских соревнований, соревнований по спортивному ориентированию и смежных мероприятий, где требуется работа с группами, этапами, штрафами, отсечками и командным зачётом.

Проект развивается на основе оригинального открытого репозитория **SportOrg / PySport**.  

Цель данной версии — сохранить совместимость с базовой логикой SportOrg и постепенно добавить инструменты, необходимые для туристских стартов.

## Основа проекта

Данный репозиторий является производной версией оригинального проекта SportOrg.

Оригинальный SportOrg — это программа для организации соревнований, работы со стартовыми протоколами, участниками, группами, результатами, отметкой SPORTident и печатными отчётами.

В этой версии сохраняется базовая структура SportOrg, но добавляются отдельные возможности для дисциплин туристской направленности.

## Что добавлено в этой версии

На текущем этапе в проект добавляется модуль **«Туризм»**.

Реализованы и дорабатываются следующие возможности:

- новый тип соревнований **«Туризм»**;

- режимы судейства:

  - **со штрафами**;

  - **без штрафов**, но с возможностью учитывать отсечки;

- создание туристских дистанций;

- привязка возрастных групп к туристским дистанциям;

- создание этапов туристской дистанции;

- задание порядка прохождения этапов;

- ввод штрафов, отсечек и снятий по этапам;

- ввод санкций для одного участника по всем этапам;

- массовый ввод штрафов, отсечек и снятий по одному этапу для нескольких участников;

- учёт снятия с отдельного этапа без полного снятия участника с дистанции;

- пересчёт результата с учётом туристских санкций;

- подготовка основы для командного зачёта по возрастным группам;

- подготовка печатных шаблонов для туристских протоколов.

## Логика туристского расчёта

В туристском модуле предусматривается следующая логика:

- штраф временем увеличивает итоговый результат участника;

- отсечка уменьшает итоговый результат;

- штрафные баллы могут переводиться во время;

- снятие с отдельного этапа не снимает участника полностью с дистанции;

- участник со снятием на этапе должен располагаться ниже участников без снятий;

- при нескольких снятиях учитывается количество снятых этапов;

- итоговый пересчёт выполняется через стандартную систему результатов SportOrg, чтобы сохранить совместимость с основными протоколами.

## Командный зачёт

В проекте планируется и частично реализуется командный зачёт для туристских стартов.

Основная логика:

- зачёт ведётся по возрастным группам;

- для каждой команды в группе выбираются лучшие результаты участников;

- количество зачётных участников настраивается;

- сумма лучших результатов используется для ранжирования команд;

- команды с участниками, но с нулевыми очками, должны отображаться в протоколе;

- команды с нулевыми очками не получают места;

- для печати можно скрывать служебные колонки.
