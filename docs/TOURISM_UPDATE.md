# Доработка SportOrg: модуль «Туризм»

Этот пакет добавляет начальное ядро судейства спортивного туризма:

- расчёт `итог = финиш - старт - отсечки + штрафное время`;
- стоимость штрафного балла;
- отсечки по этапам;
- снятие с этапа без автоматического снятия с дистанции;
- статусы `не фин.`, `сн с этапов`, `сн с дист`, `прев. КВ`, `в/к`;
- ранжирование результатов;
- командный зачёт по лучшим N результатам;
- показ команд с 0 очков без присвоения места;
- объединение мужских/женских групп через `group_map`.

## Куда копировать

Содержимое архива нужно наложить на корень репозитория `sportorg_turist`.

После копирования появятся файлы:

```text
sportorg/modules/tourism/
templates/reports/tourism/
tests/tourism/
docs/TOURISM_UPDATE.md
scripts/apply_tourism_patch.py
```

## Проверка ядра

```bash
python -m pytest tests/tourism
```

## Интеграция в SportOrg

Это первый безопасный слой: он не ломает текущую модель SportOrg и может быть подключён к GUI/шаблонам постепенно.
Следующий шаг — связать `TourismResult` с существующей моделью результата SportOrg и добавить пункт меню/настройки дистанции.
